# V2 UI Direction

## Intent

The UI should feel like a real Windows technician tool, not a script wrapper and not a marketing page.

## Keep

- WinForms.
- English UI text.
- PcNinja icon/title identity.
- Tabs: Dashboard, Updates, Schedule, Drivers, Logs.
- Fast first paint.
- Lazy log loading.
- Dark theme with PcNinja blue and restrained purple accents.

## Improve

- Dashboard becomes the main operational overview.
- Windows Update status and PcNinja Tool Update status are clearly separate.
- Health Check becomes a first-class quick action.
- Reset Windows Update remains visually separated with a red risk accent.
- Logs remain readable, scrollable, and not loaded heavily during startup.

## Dashboard V2 Sections

- System Update Overview.
- PcNinja Tool Update.
- Quick Actions.
- Schedule Summary.
- Health Check summary.

## Updates Tab

- Manual update actions.
- Candidate preview when feasible.
- Restart/reboot state.
- PcNinja Windows image link.
- PcNinja Classes link.

## Schedule Tab

- Schedule mode.
- Retry policy.
- Wake-to-run.
- Run-if-missed.
- Next run summary.

## Drivers Tab

- Driver audit actions.
- Latest report summary.
- PcNinja tool links.
- Manufacturer links remain reference/report-only.

## Logs Tab

- Explicit refresh/follow controls.
- Search/filter if feasible later.
- Keep log loading lazy.
